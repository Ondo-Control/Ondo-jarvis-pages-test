ONDO JARVIS – Memory-Probe

Nur lokal im Browser: Diese Seite lädt deine JSON nicht zu einem Server hoch. Sie liest die von dir ausgewählte Datei im Browser, verändert nur die Memory-Probe-Felder und erzeugt eine neue Datei zum Herunterladen.

Noch keine Datei ausgewählt.

Beim Vorbereiten bleiben onedrive_probe_enabled=false und onedrive_memory_enabled=false. Es wird ein öffentlicher, nicht geheimer 32-Byte-Testschlüssel nur für den synthetischen Probelauf eingetragen.

Der Testschlüssel darf niemals für produktives Memory verwendet werden. Die Rücksetzen-Funktion entfernt ihn wieder, solange produktives Memory deaktiviert ist.
